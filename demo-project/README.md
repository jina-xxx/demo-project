# Demo: History API, Canvas, Web Worker

Демо-проект, реализующий:
- навигацию через History API (кнопки «Назад»/«Вперед»);
- интерактивную графику и анимацию на Canvas с `requestAnimationFrame`;
- фоновые вычисления через Web Worker (без блокировки UI).

## Как запустить

1. Откройте `index.html` в браузере через локальный сервер (не через `file://`).
2. Примеры запуска сервера:
   - Python: `python -m http.server 8000`
   - Node.js: `npx serve`
3. Перейдите в браузере на `http://localhost:8000`.

## Функционал

- **История браузера**: кнопки Push State, Назад, Вперед.
- **Canvas**: анимированные шары, реагирующие на мышь.
- **Web Worker**: тяжёлые вычисления (факториал) в фоне.
